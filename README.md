# Auto Keybind

Script `/autokey` untuk mengulang satu tombol secara otomatis di GTA San Andreas Multiplayer (SA-MP).

## Fitur

- Panel `/autokey` dengan pilihan tombol Y, ALT, F, H, SPC (Spasi), atau N.
- Jeda antartekanan 50 sampai 10000 ms.
- Mulai dan Berhenti dari panel, serta F10 untuk berhenti.

## Unduhan

- [AutoKeybind-1.1.0.lua](monetloader/AutoKeybind-1.1.0.lua): versi terbaru.
